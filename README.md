# ICS3U CPT – Interactive Processing Project

This repository contains your ICS3U Culminating Performance Task (CPT).

## Goal: Give users a task when fish is a specific colour.

### Description of program
Using a random number generator, a blue or yellow fish will show up. If it is a blue fish, it will instruct the user to click the fish to turn the background black. If it is a yellow fish, it will tell the user to move the fish with the arrow keys. The fish will change its speech if user has met the criteria.
